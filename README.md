# Selenium Automation: Learning & Practice Repository

## 📌 Overview
This repository documents my learning journey and serves as a practical knowledge base for UI Automation using Selenium WebDriver and Java. It captures core concepts, framework design strategies, and executable test scripts built with Apache Maven.

## 📂 Repository Structure
To separate theoretical concepts from practical application, the modules are organized into two formats:
* **`docs/`**: Comprehensive markdown notes detailing core concepts, locator strategies, and framework architecture.
* **`src/test/java/`**: Executable Java test scripts demonstrating the application of Selenium concepts in real-world scenarios.

## 🎯 Learning Objectives
* Automate web browser interactions using Selenium WebDriver and Java.
* Master dynamic element identification using advanced XPath, CSS selectors, and other locator strategies.
* Implement robust synchronization techniques (Implicit, Explicit, and Fluent Waits) to handle asynchronous rendering.
* Design and execute data-driven test suites using TestNG and Apache POI.
* Architect scalable automation frameworks using the Page Object Model (POM) design pattern.
* Integrate continuous testing pipelines using Git, Maven, and Jenkins.
